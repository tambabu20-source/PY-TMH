# Theo dõi hoạt động khám, chữa bệnh và chi phí BHYT

Dashboard Bệnh viện Y học cổ truyền Phú Yên.

[Mở dashboard](https://tambabu20-source.github.io/PY-TMH/?view=1&tab=hospital)

Chọn kỳ báo cáo, khoa và nhóm chỉ tiêu; bấm số liệu để xem nguồn. Có nhập lại Excel, xuất CSV và in báo cáo.

Các ghi chú giải thích được thu gọn trong mục **Ghi chú dữ liệu**; mặc định ẩn trên giao diện và bản in.

Mã nguồn đầy đủ trong `source/hospital-dashboard.zip`. Bản website được phục vụ trực tiếp từ nhánh `main`, thư mục gốc. Giữ `index.html`, snapshot JSON hiện tại và `assets/` cùng nhau.
